Mathematical Analysis of Recursive Algorithms

Learning outcomes: form a recurrence with a base case; solve simple recurrences by expansion; verify a formula by induction; understand recursion trees and repeated subproblems.

The five-step plan

  1. Identify input size \(n\).
  2. Identify the basic operation.
  3. Write the recurrence for the operation count.
  4. State the initial/base condition.
  5. Solve the recurrence and state the order of growth.

A recurrence relation defines a function using smaller input sizes. The initial condition gives the value at the base case, for example \(T(1) = 1\).

Backward substitution

Repeatedly replace \(T(n)\) with its recurrence until the base case appears. Simplify the expression, then verify the proposed formula by mathematical induction when appropriate.

\[T(n) = T(n-1) + c,\ T(1)=d \;\Rightarrow\; T(n)=d+c(n-1) \in \Theta(n)\]\[T(n) = T(n/2) + c,\ T(1)=d \;\Rightarrow\; \Theta(\log n)\ \text{for } n \text{ a power of 2}\]\[T(n) = 2T(n/2) + cn \;\Rightarrow\; \Theta(n \log n)\ (n \text{ a power of 2})\]

Naive Fibonacci: repeated subproblems

The recursive definition \(F(n)=F(n-1)+F(n-2)\) recomputes the same values many times. Its naive running time grows exponentially (commonly bounded by \(O(2^n)\)). Memoization stores previously computed values and reduces the time to \(\Theta(n)\); an iterative implementation also uses \(\Theta(n)\) time and can use \(\Theta(1)\) extra space.

Recursion versus iteration

Recursive calls use call-stack memory. A recursion depth of \(n\) can require \(\Theta(n)\) stack space. Iteration often avoids this stack overhead. Tail recursion occurs when the recursive call is the final operation; some languages optimize it, but Python does not generally perform tail-call elimination.

Module 2 — worked examples

Example 1: Factorial

factorial(n):
    if n <= 1: return 1
    return n * factorial(n-1)

For multiplication count, \(T(1)=0\) and \(T(n)=T(n-1)+1\). Expansion gives \(T(n)=n-1\), so the time is \(\Theta(n)\) and recursion depth is \(\Theta(n)\).

Example 2: Counting binary digits

For positive integer \(n\), repeatedly divide by 2 until \(n\) becomes 0. For \(n=2^k\), the number of divisions is \(k+1\) depending on whether the final zero-check is counted. Since \(k=\log_2 n\), the time is \(\Theta(\log n)\).

Example 3: Recursive maximum (original example)

Split an array into two halves, recursively find each half's maximum, then compare the two results. The recurrence is \(T(n)=2T(n/2)+1\) with \(T(1)=0\). At each level the total combine work is proportional to the number of subarrays; there are \(\log_2 n\) levels, so \(T(n) \in \Theta(n)\).

Example 4: Fast exponentiation (original example)

Compute \(a^n\) by recursively computing \(a^{n/2}\), squaring it, and multiplying by \(a\) if \(n\) is odd. The recurrence is \(T(n)=T(\lfloor n/2\rfloor)+O(1)\), with \(T(0)=O(1)\). The input exponent is halved each step, so the time is \(\Theta(\log n)\).
