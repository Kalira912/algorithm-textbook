MODULE 2

Mathematical Analysis of Recursive Algorithms

Learning outcomes: form a recurrence with a base case; solve simple recurrences by expansion; verify by induction; understand recursion trees and repeated subproblems.

The five-step plan

  1. Identify input size \(n\).
  2. Identify the basic operation.
  3. Check whether the count depends on input cases — best, worst or average.
  4. Write the recurrence for the operation count and state the initial condition.
  5. Solve the recurrence and state the order of growth.

A recurrence relation defines a function using smaller input sizes. The initial condition gives the value at the base case, for example \(T(1)=1\). A recurrence without an initial condition has many solutions; the initial condition picks the right one.

Backward substitution

Repeatedly replace \(T(n)\) with its recurrence until the base case appears. Simplify, then verify the proposed closed form by induction.

\[T(n)=T(n-1)+c,\ T(1)=d \Rightarrow T(n)=d+c(n-1)\in\Theta(n)\] \[T(n)=T(n/2)+c,\ T(1)=d \Rightarrow \Theta(\log n)\ \text{for } n=2^k\] \[T(n)=2T(n/2)+cn \Rightarrow \Theta(n\log n)\ \text{for } n=2^k\]

Total: \(1+2+4+\dots+2^{n-1}=2^n-1\)

At level \(k\) there are \(2^k\) subproblems, each of size \(n-k\). Expanding:

\[T(n)=2T(n-1)+1=2^2T(n-2)+2+1=\dots=2^nT(0)+(2^n-1)=2^n-1\in\Theta(2^n).\]

Induction check: \(T(1)=1\); if \(T(n-1)=2^{n-1}-1\), then \(T(n)=2(2^{n-1}-1)+1=2^n-1\). ✔

Recursion tree: naive Fibonacci

Level 0:
\(F(n)\)
Level 1:
\(F(n-1)\)
\(F(n-2)\)
Level 2:
\(F(n-2)\)
\(F(n-3)\)
\(F(n-3)\)
\(F(n-4)\)
⋮
Observation:
\(F(n-2)\) recomputed twice at level 2 alone

The number of nodes grows like \(F(n+1)-1\). Since \(F(n)\sim \varphi^n/\sqrt5\) with \(\varphi=(1+\sqrt5)/2\), the naive running time is \(\Theta(\varphi^n)\) — exponential.

Binary digits

ALGORITHM BinRec(n)          // n ≥ 1
if n = 1 then return 1
else return BinRec(⌊n/2⌋) + 1
  1. Size: \(n\) (value).
  2. Basic operation: addition.
  3. Cases: one case.
  4. \[A(n)=A(\lfloor n/2\rfloor)+1,\quad A(1)=0.\]
  5. For \(n=2^k\): \(A(2^k)=A(2^{k-1})+1=\dots=A(1)+k=k\). In general \(A(n)=\lfloor\log_2 n\rfloor\in\Theta(\log n)\).

Naive Fibonacci

ALGORITHM F(n)
if n ≤ 1 return n
else return F(n-1) + F(n-2)
  1. Size: \(n\).
  2. Basic operation: addition.
  3. Cases: one case.
  4. \[A(n)=A(n-1)+A(n-2)+1,\quad A(0)=A(1)=0.\]
  5. Solution: \(A(n)=F(n+1)-1\in\Theta(\varphi^n)\) with \(\varphi=(1+\sqrt5)/2\).

Recursion vs. iteration

Each call uses a stack frame; depth \(n\) uses \(\Theta(n)\) memory. Tail recursion (call as last action) can be rewritten as a loop; Python limits recursion depth (~1000).

Module 2 — worked examples

Example 1: Factorial

  1. Size: \(n\).
  2. Basic operation: multiplication.
  3. Cases: one case.
  4. \[M(n)=M(n-1)+1,\quad M(1)=0.\]
  5. \[M(n)=M(n-1)+1=\dots=M(1)+(n-1)=n-1\in\Theta(n).\]

Example 2: Counting binary digits

  1. Size: value \(n\).
  2. Basic operation: addition.
  3. Cases: one case.
  4. \[A(n)=A(\lfloor n/2\rfloor)+1,\quad A(1)=0.\]
  5. For \(n=2^k\), \(A(n)=k=\log_2 n\); general \(A(n)=\lfloor\log_2 n\rfloor\in\Theta(\log n)\).

Example 3: Recursive maximum (original)

Split array in halves; recursive max on each half; combine with one comparison.

  1. Size: \(n\).
  2. Basic operation: comparison in combine.
  3. Cases: one case.
  4. \[T(n)=2T(n/2)+1,\quad T(1)=0.\]
  5. Recursion tree: \(\log_2 n\) levels, each with \(1+2+4+\dots=2^{\text{level}}\) combines proportional to number of subarrays at that level → total \(\Theta(n)\).

Example 4: Fast exponentiation (original)

Power(a, n):
    if n = 1: return a
    p ← Power(a, ⌊n/2⌋)
    return p*p*(n mod 2 ? a : 1)
  1. Size: \(n\).
  2. Basic operation: multiplication.
  3. Cases: one case.
  4. \[M(n)=M(\lfloor n/2\rfloor)+O(1),\quad M(1)=0.\]
  5. Halving: \(M(n)=\Theta(\log n)\). Compare naive \(n-1\).
