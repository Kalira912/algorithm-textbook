Empirical verification with Python

This experiment counts comparisons made by a linear maximum-finding algorithm. The theoretical count is \(n-1\). Run the code in Python or Google Colab and compare measured counts with the formula.

Python code

def max_with_counter(values):
    if not values:
        raise ValueError("Input must not be empty")
    current_max = values[0]
    comparisons = 0
    for value in values[1:]:
        comparisons += 1
        if value > current_max:
            current_max = value
    return current_max, comparisons

for n in [10, 100, 1000, 5000]:
    data = list(range(n))
    result, measured = max_with_counter(data)
    theoretical = n - 1
    print(f"n={n:4d}, max={result:4d}, measured={measured:4d}, formula={theoretical:4d}")

Expected interpretation: measured comparisons equal \(n-1\) for each non-empty input. This verifies the operation-count formula for this implementation. It does not measure wall-clock time, which is affected by hardware, interpreter overhead, and other factors.

Second experiment: selection sort

def selection_sort_count(a):
    n, count = len(a), 0
    for i in range(n - 1):
        m = i
        for j in range(i + 1, n):
            count += 1
            if a[j] < a[m]: m = j
        a[i], a[m] = a[m], a[i]
    return count

for n in (10, 100, 1000):
    assert selection_sort_count(list(range(n, 0, -1))) == n * (n - 1) // 2
print("formula confirmed")

Expected: the comparison count equals \(n(n-1)/2\) exactly for every \(n\) — the formula matches the code.
