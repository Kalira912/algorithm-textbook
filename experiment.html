Empirical verification

Two experiments. Each counts the basic operation and compares with the theoretical formula.

Experiment 1 (Module 1): UniqueElements

For an array of \(n\) distinct values, the algorithm compares every pair. Theoretical count:

\[C(n)=\sum_{i=0}^{n-2}\sum_{j=i+1}^{n-1}1=\frac{n(n-1)}{2}\in\Theta(n^2).\] 
def unique_elements_count(a):
    n = len(a)
    count = 0
    for i in range(n - 1):
        for j in range(i + 1, n):
            count += 1
            if a[i] == a[j]:
                return count, False
    return count, True

for n in [10, 50, 100, 500, 1000]:
    data = list(range(n))          # all distinct
    measured, unique = unique_elements_count(data)
    formula = n * (n - 1) // 2
    print(f"n={n:5d}  measured={measured:8d}  formula={formula:8d}  match={measured==formula}")

Expected: measured equals \(n(n-1)/2\) for every \(n\).

Experiment 2 (Module 2): Tower of Hanoi

The recurrence is \(T(n)=2T(n-1)+1\) with \(T(1)=1\). Theoretical count:

\[T(n)=2^n-1\in\Theta(2^n).\] 
def hanoi_moves(n, counter):
    if n == 1:
        counter[0] += 1
        return
    hanoi_moves(n - 1, counter)
    counter[0] += 1
    hanoi_moves(n - 1, counter)

for n in range(1, 16):
    c = [0]
    hanoi_moves(n, c)
    formula = 2**n - 1
    print(f"n={n:2d}  measured={c[0]:6d}  formula={formula:6d}  match={c[0]==formula}")

Expected: measured equals \(2^n-1\) for every \(n\). The counts double roughly at each step, confirming exponential growth.
